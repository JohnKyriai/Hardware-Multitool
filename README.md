Hardware Multitool v1.0 (Batch script version)

A lightweight, menu-driven Windows hardware information tool built with Batch script.

Hardware Multitool lets you quickly view key information about your computer using the wmic command built into Windows.
SUPPORTED WINDOWS VERSIONS:
- XP
- VISTA
- 7
- 8
- 8.1
- 10
- No Windows 11 sorry (unless you get wmic to work on it)
